# 每日待办

把每日清单直接放进思源笔记。打开「每日待办」下的当天文档，清单就显示在正文顶部，打勾即写回笔记——不需要额外装服务、不占端口、不用内网穿透。

## 功能

- **每日自动生成**：打开面板即按日期创建当天文档，找不到就新建
- **未完成自动结转**：昨天没做完的带到今天，带 `@` 标记的一起带走；昨天的文档只留已完成项，天然成为归档
- **从工作日志提取**：工作日志里的 `- [ ]` 任务自动汇入当天清单，同一块只提取一次
- **打勾即时回写**：面板上的勾选直接改写思源里的任务块，手机和电脑看到同一份数据
- **延后提醒**：给任务加 `@+2d` 或 `@2026-12-01`，未到期前只出现在「排队中」
- **手机可用**：界面在文档正文内渲染，桌面端和移动端走同一套实现，不依赖 Dock 或自定义页签

## 安装

思源集市 → 插件 → 搜索「每日待办」→ 安装并启用。

启用后顶栏会出现清单图标，点击即可打开面板；也可以按 `⌥⌘T`。

## 使用

1. 点顶部栏的清单图标，插件会自动创建「每日待办」根文档和当天文档
2. 之后每天打开当天文档，清单就在正文顶部，不用再点按钮
3. 点复选框完成任务，文字变删除线，文档里同步变成 `- [x]`

工作日志里这样写才会被提取：

```markdown
- [ ] 回复客户关于交付时间的邮件
- [ ] 整理上周会议纪要
- [x] 已完成的条目不会被提取
```

### 延后语法

只匹配任务末尾，正文里的 `@` 不会被误判：

```markdown
- [ ] 提交本周周报 @+2d          ← 两天后
- [ ] 预约体检 @11-24            ← 今年 11 月 24 日
- [ ] 续办证件 @2026-12-01       ← 完整日期
```

面板里点任务右侧的 `⋯` 也能直接延后。标记会固化成具体日期写入笔记，不会随时间推移失效。

## 说明

- 工作日志里的纯文字段落不会被当成待办，必须写成 `- [ ]` 任务列表
- 提取是「复制」不是「移动」，工作日志里的原文保持不变
- 某天没有打开面板，就不会生成那天的清单，下次以最近一篇为基准结转
- 清单面板注入在编辑器内容区之外，不影响文档本身的保存与同步

## 开发

```bash
npm install
npm run build      # 产物输出到 dist/
```

把 `dist/` 里的内容复制到 `{工作空间}/data/plugins/siyuan-daily-todo/` 即可本地调试。
